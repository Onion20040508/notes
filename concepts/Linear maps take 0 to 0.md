> [!theorem] 3.10 Linear maps take 0 to 0
> If $T$ is a linear map from $V$ to $W$, then $T(0)=0$.

> [!proof]-
> $T(0)=T(0+0)=T(0)+T(0)$; add the additive inverse of $T(0)$ to both sides.
