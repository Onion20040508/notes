## Connections
- **How.** Two applications of the [[First Isomorphism Theorem for Groups]] to the projection $\pi : G \to G/N$: restricted to $H$ it has kernel $H \cap N$, restricted to $HN$ kernel $N$, and the two images agree, $\pi(H) = \pi(HN)$ ([[§38 The First Isomorphism Theorem#^thm-38-4|§38.4]]).
- **Picture.** The diamond $H \cap N \le H, N \le HN$ ([[m493-38-3.svg|figure]] in [[§38 The First Isomorphism Theorem#The Second Isomorphism Theorem|§38]]): the quotients on opposite edges agree, $HN/N \cong H/(H \cap N)$.
- **Special case.** When a set of representatives for $G/N$ is a subgroup $S$, then $G/N \cong S$ ([[§38 The First Isomorphism Theorem#^cor-38-5|§38.5]], first proved directly in [[§37 Quotient Groups#^prop-37-4|§37.4]]); with $H = \operatorname{Stab}(4)$ it gives $S_4/V \cong S_3$ ([[§38 The First Isomorphism Theorem#^ex-38-2|Ex. §38.2]]).
- **Next.** The Third Isomorphism Theorem, $(G/N)/(K/N) \cong G/K$, was only named ([[§38 The First Isomorphism Theorem#^thm-38-6|§38.6]]).
