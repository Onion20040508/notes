The Cantor function $\varphi$ is continuous and increasing with $\varphi' = 0$ a.e., yet climbs from $0$ to $1$: the standard witness that a continuous BV function need not be absolutely continuous, and that the FTC can fail. All its appearances are listed in [[Cantor set and Cantor function]].

## The Cantor Function

In this chapter it shows that the integral inequality of Lebesgue's differentiation theorem can be strict, that bounded variation is not enough for the FTC, that uniform continuity does not imply absolute continuity, and that an increasing function can be purely singular and can map a null set onto $[0,1]$.
