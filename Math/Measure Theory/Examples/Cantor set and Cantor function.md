The middle-thirds Cantor set $C \subseteq [0,1]$ (first met as a closed set with empty interior in [[§13 Some Topological Concepts in Metric Spaces#^rem-13-5|451 §13]]) and the Cantor function $\varphi$ built on it. The set is compact, uncountable and null, so it separates "small in measure" from "small in cardinality"; the function is continuous, increasing and has $\varphi' = 0$ a.e., yet climbs from $0$ to $1$, so it is the standard witness that a continuous BV function need not be absolutely continuous, and that the FTC can fail. Its uses in MATH 551:

- Constructed by removing open middle thirds ([[§14 The Vitali Set and the Cantor Set#^def-14-4|§14]])
- Closed, hence Borel, hence measurable ([[§12 Borel Sets and Measure Spaces#^rem-12-2|§12]])
- Compact, no interior points, null and uncountable ([[§14 The Vitali Set and the Cantor Set#^prop-14-7|§14]])
- Measure zero does not imply countable ([[§14 The Vitali Set and the Cantor Set#^rem-14-7|§14]])
- The Cantor function: continuous and increasing with $\varphi' = 0$ a.e. ([[§31 Absolute Continuity#^ex-31-1|§31]])
- Lebesgue's inequality $\int_a^b f' \leq f(b) - f(a)$ can be strict ([[§29 Lebesgue's Differentiation Theorem#^rem-29-4|§29]])
- BV is not sufficient for the FTC ([[§31 Absolute Continuity#^rem-31-5|§31]])
- Uniformly continuous but not absolutely continuous ([[§31 Absolute Continuity#^rem-31-7|§31]])
- The prototypical purely singular increasing function ([[§32 The Fundamental Theorem of Calculus for Lebesgue Integrals#^rem-32-8|§32]])
- $BV \cap C \not\subseteq AC$ in the regularity hierarchy ([[§31 Absolute Continuity#^rem-31-9|§31]])
- It maps the null set $C$ onto $[0,1]$, unlike an AC function ([[§32 The Fundamental Theorem of Calculus for Lebesgue Integrals#^rem-32-10|§32]])
- The FTC defect $\tilde{F}$ can be non-constant ([[§31 Absolute Continuity#^rem-31-11|§31]])
