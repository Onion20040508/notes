The middle-thirds Cantor set $C \subseteq [0,1]$ (first met as a closed set with empty interior in [[§13 Some Topological Concepts in Metric Spaces#^rem-13-5|451 §13]]) and the Cantor function $\varphi$ built on it. The set is compact, uncountable and null, so it separates "small in measure" from "small in cardinality"; the function is continuous, increasing and has $\varphi' = 0$ a.e., yet climbs from $0$ to $1$, so it is the standard witness that a continuous BV function need not be absolutely continuous, and that the FTC can fail. Its uses in MATH 551:

- Constructed by removing open middle thirds ([[§11 Borel Sets and Measure Spaces#^def-11-13|§11]])
- Closed, hence Borel, hence measurable ([[§11 Borel Sets and Measure Spaces#^rem-11-2|§11]])
- Compact, no interior points, null and uncountable ([[§11 Borel Sets and Measure Spaces#^prop-11-21|§11]])
- Measure zero does not imply countable ([[§11 Borel Sets and Measure Spaces#^rem-11-7|§11]])
- The Cantor function: continuous and increasing with $\varphi' = 0$ a.e. ([[§18 Differentiation Theory#^ex-18-4|§18]])
- Lebesgue's inequality $\int_a^b f' \leq f(b) - f(a)$ can be strict ([[§18 Differentiation Theory#^rem-18-4|§18]])
- BV is not sufficient for the FTC ([[§18 Differentiation Theory#^rem-18-5|§18]])
- Uniformly continuous but not absolutely continuous ([[§18 Differentiation Theory#^rem-18-7|§18]])
- The prototypical purely singular increasing function ([[§18 Differentiation Theory#^rem-18-8|§18]])
- $BV \cap C \not\subseteq AC$ in the regularity hierarchy ([[§18 Differentiation Theory#^rem-18-9|§18]])
- It maps the null set $C$ onto $[0,1]$, unlike an AC function ([[§18 Differentiation Theory#^rem-18-10|§18]])
- The FTC defect $\tilde{F}$ can be non-constant ([[§18 Differentiation Theory#^rem-18-11|§18]])
