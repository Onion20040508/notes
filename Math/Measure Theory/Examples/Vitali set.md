A set $V \subseteq [0,1]$ containing exactly one point from each class of $x \sim y \iff x - y \in \mathbb{Q}$, chosen with the Axiom of Choice. Its translates by the rationals in $[-1,1]$ are pairwise disjoint, and their union lies between $[0,1]$ and $[-1,2]$; if $V$ were measurable, a countable sum of copies of $m(V)$ would have to lie between $1$ and $3$, which is impossible ([[The Vitali Set is Not Measurable]]). It is the course's only non-measurable set, so every "this can fail without measurability" counterexample is built from it. Its uses in MATH 551:

- Why measurability must be tested against every set ([[Measure Theory §10 Lebesgue Measurable Sets#^rem-10-2|§10]])
- Not every set is measurable ([[Measure Theory §11 Borel Sets and Measure Spaces#^rem-11-2|§11]])
- The relation $x \sim y \iff x - y \in \mathbb{Q}$ ([[Measure Theory §11 Borel Sets and Measure Spaces#^def-11-10|§11]])
- Choosing one point from each class ([[Measure Theory §11 Borel Sets and Measure Spaces#^def-11-12|§11]])
- Disjoint rational translates cover $[0,1]$ ([[Measure Theory §11 Borel Sets and Measure Spaces#^prop-11-19|§11]])
- $V$ is not measurable ([[Measure Theory §11 Borel Sets and Measure Spaces#^thm-11-20|§11]])
