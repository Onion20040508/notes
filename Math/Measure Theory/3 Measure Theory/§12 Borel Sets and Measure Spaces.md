## Generated $\sigma$-Algebras

> [!theorem] Proposition §15.1: Existence of Generated $\sigma$-Algebra
> Let $X$ be a set and $\mathcal{C}$ be a collection of subsets of $X$. Then there exists a smallest [[§11 Lebesgue Measurable Sets#^def-11-4|σ-algebra]] containing $\mathcal{C}$.

^prop-12-1

> [!proof]+ Proof
> Let $\mathfrak{I} = \{\mathcal{D} \mid \mathcal{D} \text{ is a } \sigma\text{-algebra and } \mathcal{D} \supseteq \mathcal{C}\}$.
>
> Note that $\mathfrak{I} \neq \emptyset$ since $\mathcal{P}(X) \in \mathfrak{I}$.
>
> Let $\mathcal{A} = \bigcap_{\mathcal{D} \in \mathfrak{I}} \mathcal{D}$.
>
> We claim $\mathcal{A}$ is a $\sigma$-algebra:
> - If $E \in \mathcal{A}$, then $E \in \mathcal{D}$ for all $\mathcal{D} \in \mathfrak{I}$. Since each $\mathcal{D}$ is a $\sigma$-algebra, $E^c \in \mathcal{D}$ for all $\mathcal{D} \in \mathfrak{I}$. Thus $E^c \in \mathcal{A}$.
> - If $E_j \in \mathcal{A}$ for $j = 1, 2, \ldots$, then $E_j \in \mathcal{D}$ for all $\mathcal{D} \in \mathfrak{I}$. Thus $\bigcup_j E_j \in \mathcal{D}$ for all $\mathcal{D} \in \mathfrak{I}$, so $\bigcup_j E_j \in \mathcal{A}$.
>
> Since $\mathcal{C} \subseteq \mathcal{D}$ for all $\mathcal{D} \in \mathfrak{I}$, we have $\mathcal{C} \subseteq \mathcal{A}$.
>
> By construction, $\mathcal{A}$ is the smallest such $\sigma$-algebra.

^pf-12-1

*Uses:* [[§11 Lebesgue Measurable Sets#^def-11-4|Def. §11.4]], [[§11 Lebesgue Measurable Sets#^ex-11-2|Ex. §11.2]]

> [!definition] Definition §15.1: Generated $\sigma$-Algebra
> The smallest $\sigma$-algebra containing a collection $\mathcal{C}$ is called the **$\sigma$-algebra generated by $\mathcal{C}$**.

^def-12-1

> [!definition] Definition §15.2: Borel $\sigma$-Algebra
> The smallest $\sigma$-algebra containing all [[§5 Topology of ℝⁿ#^def-5-2|open subsets]] of $\mathbb{R}^n$ is called the **Borel $\sigma$-algebra**, denoted $\mathcal{B}(\mathbb{R}^n)$ or simply $\mathcal{B}$.
>
> A set in the Borel $\sigma$-algebra is called a **Borel set**.

^def-12-2

> [!remark]- Connections
> - The open sets of $\mathbb{R}^n$ form the standard topology ([[§1 Topological Spaces#^def-1-1|590 Def. §1.1]]); $\mathcal{B}$ is the σ-algebra this topology generates.

> [!example] Example §15.1
> Any open set $O \subseteq \mathbb{R}^n$ is a Borel set (by definition). Any [[§5 Topology of ℝⁿ#^def-5-3|closed set]] is also Borel (as the complement of an open set).

^ex-12-1

## Abstract Measure Theory

The construction of Lebesgue measure generalizes to abstract settings.

> [!definition] Definition §15.3: Outer Measure (General)
> Let $X$ be a set. An **outer measure** on $X$ is a function $\mu^{\ast}: \mathcal{P}(X) \to [0, \infty]$ satisfying:
> 1. $\mu^*(\emptyset) = 0$ and $\mu^*(A) \geq 0$ for all $A \subseteq X$
> 2. **Monotonicity:** $A \subseteq B \Rightarrow \mu^{\ast}(A) \leq \mu^{\ast}(B)$
> 3. **Countable subadditivity:** $\mu^{\ast}\left( \bigcup_{j=1}^{\infty} A_j \right) \leq \sum_{j=1}^{\infty} \mu^{\ast}(A_j)$

^def-12-3

> [!remark]- Connections
> - Lebesgue outer measure is the model: [[§10 Lebesgue Outer Measure#^def-10-4|Def. §10.4]] with [[Properties of Lebesgue Outer Measure|Prop. §10.1]].

> [!definition] Definition §16.1: Measurable Set (General)
> Given an outer measure $\mu^{\ast}$ on $X$, a set $E \subseteq X$ is **$\mu^{\ast}$-measurable** if for all $T \subseteq X$:
>
> $$
> \mu^*(T) = \mu^*(T \cap E) + \mu^*(T \cap E^c).
> $$

^def-12-4

> [!theorem] Theorem §15.2: Carathéodory's Theorem
> Let $\mu^*$ be an outer measure on $X$. The collection $\mathcal{A}$ of $\mu^*$-measurable sets is a $\sigma$-algebra, and $\mu^*$ restricted to $\mathcal{A}$ is countably additive.

^thm-12-2

> [!remark] Remark
> The proof of Carathéodory's theorem uses only the properties of outer measure, not any special features of $\mathbb{R}^n$. This is why the theory generalizes.

^rem-12-1

> [!remark]- Connections
> - The $\mathbb{R}^n$ case, proved in full: [[§11 Lebesgue Measurable Sets#^thm-11-1|Thm. §11.1]], [[§11 Lebesgue Measurable Sets#^lem-11-2|Lemma §11.2]], [[Lebesgue Measurable Sets Form a σ-Algebra|Thm. §11.3]].

> [!definition] Definition §16.2: Measurable Space
> A **measurable space** is a pair $(X, \mathcal{A})$ where $X$ is a set and $\mathcal{A}$ is a $\sigma$-algebra of subsets of $X$.
>
> If $E \in \mathcal{A}$, we say $E$ is **measurable**.

^def-12-5

> [!definition] Definition §17.1: Measure
> Let $(X, \mathcal{A})$ be a measurable space. A **measure** on $(X, \mathcal{A})$ is a function $\mu: \mathcal{A} \to [0, \infty]$ satisfying:
> 1. $\mu(\emptyset) = 0$
> 2. $\mu(E) \geq 0$ for all $E \in \mathcal{A}$
> 3. **Countable additivity:** If $E_j \in \mathcal{A}$ for $j = 1, 2, \ldots$ are pairwise disjoint, then
>
> $$
> \mu\left( \bigcup_{j=1}^{\infty} E_j \right) = \sum_{j=1}^{\infty} \mu(E_j).
> $$

^def-12-6

> [!definition] Definition §17.2: Measure Space
> A **measure space** is a triple $(X, \mathcal{A}, \mu)$ where $(X, \mathcal{A})$ is a measurable space and $\mu$ is a measure on $(X, \mathcal{A})$.

^def-12-7

> [!remark]- Connections
> - Lebesgue measure $(\mathbb{R}^n, \mathcal{M}, m)$: [[§11 Lebesgue Measurable Sets#^def-11-5|Def. §11.5]] with [[Lebesgue Measurable Sets Form a σ-Algebra|Thm. §11.3]].
> - New measures from integrals: [[§21 Consequences of the Monotone Convergence Theorem#^def-21-1|Def. §21.1]]; $L^p$ over a general measure space: [[§34 Normed Linear Spaces and Lᵖ Spaces#^def-34-6|Def. §34.6]].

> [!example] Example §15.2: Examples of Measures
> - **Counting measure:** $(X, \mathcal{P}(X), \mu)$ where $\mu(E) = |E|$ (the [[§10 Counting#^def-10-1|cardinality]], 250 Def. §10.1) if $E$ is finite, and $\mu(E) = \infty$ if $E$ is infinite.
> - **Dirac measure:** Fix $x_0 \in X$. Define $\mu_{x_0}(E) = 1$ if $x_0 \in E$ and $\mu_{x_0}(E) = 0$ if $x_0 \notin E$.

^ex-12-2

> [!remark]- Connections
> - Computational version: the Dirac measure is the delta function of ODEs, [[§30 Impulse Functions#^def-30-3|331 Def. §30.3]], and integrating against it is the sifting property, [[§30 Impulse Functions#^thm-30-3|331 Thm. §30.3]] (with worked examples).

> [!theorem] Proposition §15.3
> Given any outer measure $\mu^*$ on $\mathcal{P}(X)$, we can induce a measure $\mu$ on the $\sigma$-algebra of $\mu^*$-measurable sets by restriction.

^prop-12-3

## Simplifying the Measurability Test

> [!theorem] Proposition §15.4: Rectangle Test for Measurability
> Let $E \subseteq \mathbb{R}^n$. If for every rectangle $I$:
>
> $$
> m^*(I) \geq m^*(I \cap E) + m^*(I \cap E^c),
> $$
>
> then $E$ is L-measurable.

^prop-12-4

> [!proof]+ Proof
> We must show that for all $T \subseteq \mathbb{R}^n$: $m^*(T) \geq m^*(T \cap E) + m^*(T \cap E^c)$.
>
> Let $T \subseteq \mathbb{R}^n$ with $m^*(T) < \infty$. For any $\epsilon > 0$, there exists an L-covering $\{I_k\}$ of $T$ by open rectangles such that
>
> $$
> m^*(T) + \epsilon \geq \sum_k |I_k|.
> $$
>
> By a previous result (homework; [[§10 Lebesgue Outer Measure#^prop-10-2|Prop. §10.2]]), $m^*(I_k) = |I_k|$ for open rectangles.
>
> By hypothesis, $|I_k| = m^*(I_k) \geq m^*(I_k \cap E) + m^*(I_k \cap E^c)$.
>
> Thus:
>
> $$
> m^*(T) + \epsilon \geq \sum_k |I_k| \geq \sum_k m^*(I_k \cap E) + \sum_k m^*(I_k \cap E^c).
> $$
>
> By [[Properties of Lebesgue Outer Measure|subadditivity]]:
>
> $$
> \sum_k m^*(I_k \cap E) \geq m^*\left( \bigcup_k (I_k \cap E) \right) = m^*\left( \left( \bigcup_k I_k \right) \cap E \right) \geq m^*(T \cap E),
> $$
>
> where the last inequality uses $T \subseteq \bigcup_k I_k$ and monotonicity.
>
> Similarly, $\sum_k m^*(I_k \cap E^c) \geq m^*(T \cap E^c)$.
>
> Therefore $m^*(T) + \epsilon \geq m^*(T \cap E) + m^*(T \cap E^c)$.
>
> Since $\epsilon > 0$ is arbitrary, $m^*(T) \geq m^*(T \cap E) + m^*(T \cap E^c)$.

^pf-12-4

*Uses:* [[§10 Lebesgue Outer Measure#^rem-10-1|Rem. §9.1]], [[§10 Lebesgue Outer Measure#^prop-10-2|§10.2]], [[Properties of Lebesgue Outer Measure|§10.1]], [[§11 Lebesgue Measurable Sets#^rem-11-1|Rem. §10.1]]

> [!theorem] Proposition §15.5: Rectangles are Measurable
> Any rectangle $R \subseteq \mathbb{R}^n$ is L-measurable.

^prop-12-5

> [!proof]+ Proof
> By [[§12 Borel Sets and Measure Spaces#^prop-12-4|the rectangle test]], it suffices to show that for any rectangle $I$:
>
> $$
> m^*(I) \geq m^*(I \cap R) + m^*(I \cap R^c).
> $$
>
> Now $I \cap R$ is a rectangle (possibly empty), so $m^*(I \cap R) = |I \cap R|$.
>
> The set $I \cap R^c$ is a union of finitely many disjoint rectangles $\{I_1, \ldots, I_k\}$ together with finitely many pieces of their faces (this can be verified geometrically). Each face lies in open rectangles of arbitrarily small volume, so it has outer measure zero, and subadditivity gives $m^*(I \cap R^c) \leq \sum_{j=1}^{k} |I_j|$.
>
> Thus:
>
> $$
> m^*(I \cap R) + m^*(I \cap R^c) \leq |I \cap R| + \sum_{j=1}^{k} |I_j| = |I| = m^*(I),
> $$
>
> where the equality $|I \cap R| + \sum_j |I_j| = |I|$ follows from the fact that $I$ is partitioned into $I \cap R$ and the $I_j$ (up to the shared faces, which have volume zero).

^pf-12-5

*Uses:* [[§12 Borel Sets and Measure Spaces#^prop-12-4|§12.4]], [[§10 Lebesgue Outer Measure#^prop-10-2|§10.2]], [[Properties of Lebesgue Outer Measure|§10.1]]

![[m551-11-1.svg]]
*Why a rectangle $R$ (blue) passes the rectangle test: extending the edges of $R$ (dashed) cuts the test rectangle $I$ into $I \cap R$ and finitely many rectangles $I_1, \dots, I_5$ (red) that fill $I \cap R^c$, and the volumes of all the pieces add up to $|I|$. (The shared edges have volume zero and do not affect the count.)*

## Open Sets and Borel Sets are Measurable

> [!theorem] Theorem §16.1: Open Sets are Measurable
> Any open set $O \subseteq \mathbb{R}^n$ is L-measurable.

^thm-12-6

> [!proof]+ Proof
> If $n = 1$: By a previous result ([[Open Sets in ℝ are Countable Unions of Disjoint Open Intervals|Prop. §7.2]]), $O$ is a countable union of mutually disjoint open intervals. Each open interval is a rectangle, hence measurable. Since $\mathcal{M}$ is a [[Lebesgue Measurable Sets Form a σ-Algebra|σ-algebra]], $O \in \mathcal{M}$.
>
> If $n > 1$: By a previous result ([[§7 Structure of Open Sets#^prop-7-3|Prop. §7.3]]), $O$ is a countable union of half-open half-closed rectangles. Each such rectangle is measurable: it is the open rectangle with the same edges (measurable by [[§12 Borel Sets and Measure Spaces#^prop-12-5|Prop. §12.5]]) together with part of its boundary, and the boundary is a finite union of faces of outer measure zero, hence measurable ([[§11 Lebesgue Measurable Sets#^ex-11-1|Ex. §11.1]]). So $O \in \mathcal{M}$.

^pf-12-6

*Uses:* [[Open Sets in ℝ are Countable Unions of Disjoint Open Intervals|§7.2]], [[§7 Structure of Open Sets#^prop-7-3|§7.3]], [[§12 Borel Sets and Measure Spaces#^prop-12-5|§12.5]], [[Lebesgue Measurable Sets Form a σ-Algebra|§11.3]], [[§11 Lebesgue Measurable Sets#^ex-11-1|Ex. §11.1]]

> [!remark]- Connections
> - The 1D structure theorem is also stated in MATH 451: [[§13 Some Topological Concepts in Metric Spaces#^rem-13-5|451 Rem. §13.5]].

> [!theorem] Corollary §16.2
> Since $\mathcal{M}$ is a $\sigma$-algebra containing all open sets ([[Lebesgue Measurable Sets Form a σ-Algebra|Thm. §11.3]], [[§12 Borel Sets and Measure Spaces#^thm-12-6|Thm. §12.6]]), and the [[§12 Borel Sets and Measure Spaces#^def-12-2|Borel σ-algebra]] is the *smallest* $\sigma$-algebra containing all open sets, we have $\mathcal{B} \subseteq \mathcal{M}$.
>
> In particular, **all Borel sets are L-measurable**.

^cor-12-7

*Uses:* [[Lebesgue Measurable Sets Form a σ-Algebra|§11.3]], [[§12 Borel Sets and Measure Spaces#^thm-12-6|§12.6]], [[§12 Borel Sets and Measure Spaces#^def-12-2|Def. §12.2]]

> [!remark] Remark: The Borel Hierarchy and Measurability
> The inclusion $\mathcal{B} \subseteq \mathcal{M}$ is extremely useful in practice: any set that can be constructed from open sets using countable unions, countable intersections, and complements is automatically Lebesgue measurable. This includes:
> - All open and closed sets
> - Countable intersections of open sets ($G_\delta$ sets, [[§13 Approximation and Continuity of Measure#^def-13-1|Def. §13.1]])
> - Countable unions of closed sets ($F_\sigma$ sets, [[§13 Approximation and Continuity of Measure#^def-13-2|Def. §13.2]])
> - Any set built from these by iterating countable operations
>
> In particular, to show a set like the [[§14 The Vitali Set and the Cantor Set#^def-14-4|Cantor set]] is measurable, we need only observe that it is closed (hence Borel) — no direct verification of the Carathéodory condition is required.
>
> This raises natural questions:
> 1. **Is $\mathcal{B} = \mathcal{M}$?** No — there exist Lebesgue measurable sets that are not Borel. (The proof requires more advanced tools.)
> 2. **Is every subset of $\mathbb{R}^n$ measurable?** No — we will construct the [[§14 The Vitali Set and the Cantor Set#^def-14-3|Vitali set]], which is [[The Vitali Set is Not Measurable|not]] in $\mathcal{M}$. Such sets cannot be built from open sets by countable operations; their construction requires the Axiom of Choice.
> 3. **How close are measurable sets to Borel sets?** Very close! The approximation theorems below ([[Outer Regularity of Lebesgue Measure|Thm. §13.1]], [[Inner Regularity of Lebesgue Measure|Thm. §13.3]]) show that every measurable set differs from a Borel set ($G_\delta$ or $F_\sigma$) by a set of measure zero.

^rem-12-2

The approximation theorems and continuity of measure continue in [[§13 Approximation and Continuity of Measure]]; the Vitali set and the Cantor set follow in [[§14 The Vitali Set and the Cantor Set]].
