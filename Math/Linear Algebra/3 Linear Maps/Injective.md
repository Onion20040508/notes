> [!definition] 3.14 Injective
> A function $T:V\to W$ is *injective* if $Tu=Tv$ implies $u=v$; equivalently, distinct inputs give distinct outputs.

- For linear maps it suffices to test $0$: [[Injectivity ⟺ null space equals {0}]].
