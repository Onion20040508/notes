## Connections
- **Used for.** Graph charts on regular level sets: the [[Regular Value Theorem (Euclidean)]] and its smooth form [[Regular Level Sets Are Smooth Manifolds]]. The scalar case gives SL(n,ℝ) ([[§4 The Regular Value Theorem#^cor-4-2|§4.2]], [[§5 Topological Groups and Classical Matrix Groups#^cor-5-13|§5.13]]), and the theorem shows that the external and internal descriptions of a manifold in ℝⁿ⁺ᵏ agree ([[§9 Manifolds in Euclidean Space#^thm-9-1|§9.1]]).
- **Which variables.** It solves for the y whose square block of partials is invertible, and which coordinates work changes from point to point ([[§4 The Regular Value Theorem#^rem-4-4|Which Variables Are Solved For]]). On the circle at (1, 0) one cannot solve for y but can solve for x ([[§12 The Implicit Function Theorem#^ex-12-2|452 Ex. §12.2]]). At a critical value the level set can collapse: x² + y² = 0 is a single point, not a curve ([[§4 The Regular Value Theorem#^ex-4-1|Ex. §4.1]]).
- **Same idea elsewhere.** 452 proves the one-equation version ([[Implicit Function Theorem]], [[§12 The Implicit Function Theorem#^thm-12-2|452 §12.2]]) and uses it to prove the [[Inverse Function Theorem (several variables)]]; Lee goes the other way, applying the inverse theorem to (x, y) ↦ (x, Φ(x, y)). 452 also derives the [[Method of Lagrange Multipliers]] from it.
