## The Unit Circle

The unit circle $x^2 + y^2 = 1$, as the level set of $x^2 + y^2 - 1$, is the first test case for the implicit function theorem and for Lagrange multipliers.

The implicit function theorem solves for $y$ near $(0,1)$.

![[§12 The Implicit Function Theorem#^ex-12-1]]

It fails at $(1,0)$, where the circle is vertical.

![[§12 The Implicit Function Theorem#^ex-12-2]]

Maximize $xy$ on the unit circle: the problem that motivates Lagrange multipliers.

## Polar Coordinates

The coordinate change $x = r\cos\theta$, $y = r\sin\theta$ is the running example of a Jacobian and of a pair of inverse maps with reciprocal Jacobians.

Cartesian to polar: the Jacobian is $1/r$.

![[§13 The Inverse Function Theorem#^ex-13-3]]

Polar to Cartesian: the Jacobian is $r$.

![[§13 The Inverse Function Theorem#^ex-13-4]]

The two Jacobians are reciprocal.
