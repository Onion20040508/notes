## The Function 2xy∕(x²+y²)

The function $f(x,y) = \dfrac{2xy}{x^2 + y^2}$ with $f(0,0) = 0$. In polar coordinates $f = \sin 2\theta$: it is constant on each line through the origin, with a different constant on each line. In Chapter 1 it shows that a function can be well behaved along the axes and still fail to be continuous at the origin.

Not continuous at the origin: $f(x,x) = 1$ along $y = x$.

No limit at the origin: along $y = kx$ the value depends on $k$.
