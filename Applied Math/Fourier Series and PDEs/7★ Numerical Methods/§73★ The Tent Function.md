## The Tent Function

The tent, $2x$ on $0 < x < \frac12$ and $2(1 - x)$ on $\frac12 < x < 1$, is the initial displacement of the plucked string run through the central-difference scheme, and the boundary value on the top and bottom of a square run through the five-point scheme and compared with the series solution.
