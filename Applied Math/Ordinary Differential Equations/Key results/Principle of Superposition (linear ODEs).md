## Connections
- The computation in the proof ([[§18 Solutions of Linear Homogeneous Equations; the Wronskian#^pf-18-2|§18]]) says that $L$ is a linear map, $L[c_1y_1 + c_2y_2] = c_1L[y_1] + c_2L[y_2]$, so the solution set of $L[y] = 0$ is its null space and hence a subspace: [[§8 Null Spaces and Ranges#^ladr-3-13|LADR 3.13]], [[§30 Null Spaces, Column Spaces, and Linear Transformations#^thm-30-5|235 Thm. §30.5]].
