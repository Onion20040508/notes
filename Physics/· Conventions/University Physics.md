# University Physics

Conventions of the introductory level (level A) of every physics subject; rows marked "Level B" add the conventions of the upper-level notes built on it (Oscillations, Waves and Optics; Classical Mechanics; Thermal and Statistical Physics; Quantum Mechanics; Electromagnetism; Relativity).

| Item | Choice |
| --- | --- |
| Units | SI (kg, m, s, A, K, mol); force in newtons, $1\ \mathrm{N} = 1\ \mathrm{kg\cdot m/s^2}$ |
| Vectors | arrow over the symbol, $\vec F$; magnitude $F = \lvert\vec F\rvert$ |
| Unit vectors | $\hat\imath, \hat\jmath, \hat k$ along $x, y, z$ |
| Free fall | $g = 9.80\ \mathrm{m/s^2}$ near Earth's surface |
| Net force | $\vec F_{\text{net}} = \sum \vec F$, the vector sum of the external forces only |
| Signs in 1D problems | choose a positive direction per problem and state it |
| Sinusoids (oscillations) | $x(t) = A\cos(\omega t + \phi)$ with $A \ge 0$ and phase constant $\phi$ in radians; $\omega = 2\pi f = 2\pi/T$ |
| Oscillator frequencies | $\omega_0 = \sqrt{k/m}$ natural, $\omega'$ damped, $\omega$ driving; damping rate $\gamma = b/m$; quality factor $Q = \omega_0/\Delta\omega = m\omega_0/b$. Drive $F_0\cos\omega t$, steady state $A\cos(\omega t - \delta)$, lag $\delta \in [0, \pi]$ |
| Travelling waves | $y(x,t) = A\sin(kx - \omega t + \phi)$ moves toward $+x$, $kx + \omega t$ toward $-x$; $k = 2\pi/\lambda$, $v = f\lambda = \omega/k$. String tension $F_T$, linear density $\mu$. The frequency is unchanged at a boundary |
| Sound | displacement $s = s_{\max}\cos(kx \mp \omega t + \phi)$, pressure $\Delta p = \Delta p_{\max}\sin(kx \mp \omega t + \phi)$; bulk modulus $B$, sound level $\beta$ in dB; $M$ in $\sqrt{\gamma RT/M}$ is the molar mass (kg/mol); harmonic $n$ has frequency $n f_1$ |
| Doppler effect (sound) | source and observer speeds $v_s$, $v_o$ measured relative to the medium; upper signs for motion toward the other party |
| Light at interfaces | angles measured from the normal; $n_1$ is the medium of the incident light; polarization direction = direction of $\vec E$ |
| Interference and diffraction | $\theta$ from the original beam direction (slits, gratings) but from the crystal planes in Bragg's law; slit separation $d$, slit width $D$ (Diffraction chapter; UP's ch. 3 $D$ is the screen distance, written $L$ there); $\lambda_0$ vacuum, $\lambda_n = \lambda_0/n$ in a medium |
| Mirrors and lenses | $d_o$, $d_i$ along the axis from the vertex or lens centre; $d_o > 0$ real object; $d_i > 0$ real image, $< 0$ virtual; $f > 0$ concave mirror or converging lens; $R > 0$ concave mirror or surface convex toward the object; $m = h_i/h_o = -d_i/d_o$, positive = upright |
| Image equations | $1/d_o + 1/d_i = 1/f$ (mirrors, thin lenses); $n_1/d_o + n_2/d_i = (n_2 - n_1)/R$ (one refracting surface) |
| Optical instruments | power $P = 1/f$ in diopters ($1\ \mathrm D = 1\ \mathrm m^{-1}$); near point 25 cm; angular magnification $M = \theta_{\text{image}}/\theta_{\text{object}}$, negative if inverted |
| Relativity frames | S and S′ in standard configuration: S′ moves with velocity $v$ along $+x$, origins coincide at $t = t' = 0$; $v$ is a frame velocity, $u$ a particle velocity; $\beta = v/c$, $\gamma = 1/\sqrt{1 - v^2/c^2}$, and $\gamma_u$ for a particle's speed when both appear |
| Spacetime | diagrams with $x$ horizontal and $ct$ vertical in the same unit; interval $\Delta s^2 = \Delta r^2 - c^2\Delta t^2$ (University Physics' sign, positive for spacelike pairs; Tipler, Morin and PHY 284 use the opposite sign); proper time $c^2\Delta\tau^2 = -\Delta s^2$ |
| Relativistic dynamics | $m$ is always the rest mass (no relativistic mass); energies in MeV, momenta in MeV/$c$, masses in MeV/$c^2$; Doppler for light with $\beta > 0$ when source and observer separate |
| Quantum constants | $\hbar = h/2\pi$; $hc = 1240\ \mathrm{eV\cdot nm} = 1240\ \mathrm{MeV\cdot fm}$; $\hbar c = 197.3\ \mathrm{eV\cdot nm}$; $ke^2 = 1.440\ \mathrm{eV\cdot nm}$; $m_ec^2 = 511\ \mathrm{keV}$; $a_0 = 0.0529\ \mathrm{nm}$; $\mu_B = 5.79\times10^{-5}\ \mathrm{eV/T}$ |
| Wave functions | $\Psi(x,t)$ time-dependent, $\psi(x)$ stationary; $\Psi^*$ complex conjugate; free wave toward $+x$: $Ae^{i(kx - \omega t)}$; $\hat p = -i\hbar\,\partial/\partial x$, $\hat E = i\hbar\,\partial/\partial t$; $\Delta x$, $\Delta p$ are standard deviations |
| 1D potentials | potential energy $U$, well depth or barrier height $U_0$ (Tipler and PHY 284 write $V$, $V_0$); box on $0 \le x \le L$ with $n = 1, 2, \dots$; oscillator $n = 0, 1, \dots$, length $a = \sqrt{\hbar/m\omega}$; finite well on $-a < x < a$; decay constant $\alpha = \sqrt{2m(U_0 - E)}/\hbar$; transmission $T = (k_2/k_1)\lvert C/A\rvert^2$ |
| Atoms | quantum numbers $n, l, m_l, s, m_s$; spectral series $1/\lambda = R(1/n_f^2 - 1/n_i^2)$ with $R_H$ for hydrogen and $R_\infty$ for infinite nuclear mass; magnetic moments $\vec\mu = -g\mu_B\vec J/\hbar$ with $g_L = 1$, $g_s \approx 2$, energy $U = -\vec\mu\cdot\vec B$ |
| Nuclei and particles | nuclide $^A_Z\mathrm X$; Q-values from neutral-atom masses; mean lifetime $\bar T$ (Tipler: $\tau$), half-life $T_{1/2} = \bar T\ln 2$; Feynman diagrams with time upward; strange quark $S = -1$; $H_0 \approx 70\ \mathrm{km/s/Mpc}$ |
| Level B: complex method | oscillators and mechanical waves (B1–B7): complex time dependence $e^{+i\omega t}$ (as in the user's series and Schwartz's oscillator lectures), physical quantity = real part; optics (B8–B13): $e^{i(\vec k\cdot\vec r - \omega t)}$ with complex index $\tilde n = n + i\kappa$ (Fowles, Schwartz's optics lectures); tilde for complex functions, hat for complex constants, star for the conjugate; free oscillation $\mathrm{Re}[\hat C e^{i\omega t}]$ with $\hat C = Ae^{i\phi}$; quantum mechanics uses $e^{-i\omega t}$ |
| Level B: response | $\gamma = b/m$ (the series writes $\beta = \gamma/2$), $Q = \omega_0/\gamma$, $\omega_d = \sqrt{\omega_0^2 - \gamma^2/4}$; response function $\chi(\omega) = 1/p(i\omega)$ with force-to-displacement transfer $\chi(\omega)/m$; lag $\delta = \arg p(i\omega) \in [0, \pi)$; peak frequencies $\omega_m$ (displacement), $\omega_0$ (velocity, power), $\omega_a$ (acceleration) |
| Level B: modes and chains | mass, stiffness and dynamical matrices $\mathsf M$, $\mathsf K$, $\mathsf A = \mathsf M^{-1}\mathsf K$; normal coordinates $q = (x_1 \pm x_2)/2$; chain spacing $a$, phase step $\theta = ka$, $\omega_0^2 = k/m$; continuum $\mu = m/a$, $c^2 = T/\mu$ (level A writes $v$) |
| Level B: Fourier | $\tilde f(\omega) = \frac{1}{2\pi}\int f(t)e^{-i\omega t}\,dt$, $f(t) = \int \tilde f(\omega)e^{+i\omega t}\,d\omega$, the same in $x$ and $k$ (a right-moving wave $e^{i(\omega t - kx)}$ sits at $-k$); string fundamental period $\tau_1 = 2L/c$; membrane tension $\tau$ and areal density $\sigma$ |
| Level B: impedance and energy | internal force $F$ = force of the left part on the right part; impedance $Z = F/v$, characteristic impedance $Z_0 = \sqrt{K\mu} = \mu c = K/c$; specific acoustic impedance $z = \rho c$, pipe acoustic impedance $Z_A = \Delta p/U = \rho c/S$; energy flux $P(x,t)$; power coefficients $\mathcal R$, $\mathcal T$ |
| Level B: polarization and interfaces | handedness on the real field: right-circular = clockwise for an observer facing the oncoming wave (Fowles), Jones vector $(1, -i)/\sqrt2$ (helicity names are the opposite); s (TE) and p (TM) unit vectors as in Fowles, Schwartz and PHY 300 so that $r_p = r_s$ at normal incidence; reflected Jones vectors in the frame $(-\hat p_r, \hat s)$, reflection matrix $\mathrm{diag}(-r_p, r_s)$; interface $z = 0$, plane of incidence $xz$ |
| Level B: coherence and diffraction | $\Gamma_{12}(\tau) = \langle E_1(t)E_2^*(t+\tau)\rangle$ (Fowles's order), $\gamma \propto e^{+i\bar\omega\tau}$; within one medium $I = \lvert E\rvert^2$, across media $T = (n_T/n_0)\lvert t\rvert^2$; reduced field $\mathcal H = Z_0 H$; Fraunhofer kernel $e^{-i(\mu x + \nu y)}$ with $(\mu,\nu) = k(X,Y)/f$ (Fowles, Schwartz and PHY 300 write $e^{+i\ldots}$, which mirrors the pattern); obliquity $K = (\cos\chi + \cos\chi')/2$; Fresnel number $N_F = a^2/\lambda L$ |
| Level B: rays and materials | ray vector $(\rho, \theta)$ with true angles, ABCD matrices, $\det M = n_{\text{in}}/n_{\text{out}}$; complex index $\tilde n = n + i\kappa$, $\tilde k = k + i\alpha$, absorption coefficient $2\alpha$; susceptibility $\chi_e$, polarizability $\alpha_{\text{pol}}$, plasma frequency $\omega_p$, skin depth $\delta$ (note the clashes with $\kappa$ as dielectric constant in EM level A and $\delta$ as phase lag in B1) |
| Level B (CM): energies and coordinates | kinetic energy $T$ (level A writes $K$), potential energy $U$ (Morin and the user's series write $V$), Lagrangian $L = T - U$ (written $\mathcal L$ when $L$ is also an angular momentum), angular momentum $\vec L$; plane polar angle $\varphi$; spherical $(r, \theta, \varphi)$ with $\theta$ polar (the 452 notes swap the angles) |
| Level B (CM): analytical mechanics | generalized coordinates $q_i$, momenta $p_i = \partial L/\partial\dot q_i$, energy function $h = \sum p_i\dot q_i - L$, Hamiltonian $H(q,p,t)$; Poisson bracket $\{f,g\} = \sum(\partial_q f\,\partial_p g - \partial_p f\,\partial_q g)$ (Landau's sign is opposite); new Hamiltonian $K = H + \partial F/\partial t$; generating functions $F_1$–$F_4$; principal function $S$, characteristic function $W$; constraint multipliers $\frac{d}{dt}\partial L/\partial\dot q - \partial L/\partial q = \sum\lambda\,\partial f/\partial q$ |
| Level B (CM): orbits, frames, rigid bodies | reduced mass $\mu$, $\vec r = \vec r_2 - \vec r_1$ (H&S; Morin and Landau use the opposite), force constant $\alpha = Gm_1m_2$, semi-latus rectum $p$, $u = 1/r$, apsidal angle $\Phi$; rotating frames $(d/dt)_{\text{in}} = (d/dt)_{\text{rot}} + \vec\omega\times$, fictitious forces translational, centrifugal, Coriolis, azimuthal; Earth rate $\Omega$, latitude $\lambda$, local axes $x$ east, $y$ north, $z$ up; inertia tensor $\mathsf I$, Euler angles $z$-$x$-$z$ $(\varphi, \theta, \psi)$ |
| Level B (TH): thermodynamics | internal energy $U$ (level A writes $E_{\text{int}}$); first law $dU = đQ - p\,dV$ with work done *by* the system (Blundell and Schroeder write work *on* the system — converted); $đ$ for inexact differentials; potentials $H$, $F = U - TS$, $G = H - TS$, grand potential $\Phi = F - \mu N$; volume expansivity $\alpha$ (level A writes $\beta$), compressibilities $\kappa_T$, $\kappa_S$; heat capacities $C_V$, $C_p$ extensive ($C_{p,m}$ molar); Joule–Thomson coefficient $\mu_{JT}$; magnetic work $-m\,dB$ |
| Level B (TH): statistical mechanics | multiplicity $\Omega$ (level A writes $W$), $\beta = 1/k_BT$, canonical $Z$, grand canonical $\mathcal Z$, fugacity $z = e^{\beta\mu}$; thermal wavelength $\lambda_{\text{th}}$ and quantum concentration $n_Q$; single-particle energies $\varepsilon$, density of states $g(\varepsilon)$, occupations $f_{BE}$, $f_{FD}$, $f_{MB}$; $\mathrm{Li}_s$, $\zeta(s)$, $\Gamma(s)$; Debye temperature $T_D$; thermal conductivity $\kappa$ (level A writes $k$), $H = -\sum P\ln P$ |
| Level B (QM): wave mechanics and formalism | potential energy $V$ (level A writes $U$), kinetic $T$; $\Psi(x,t)$, stationary $\psi(x)$, $\Psi = \psi e^{-iEt/\hbar}$; operators $\hat Q$, $\langle Q\rangle$, $\sigma_Q$, $\hat H$ (level A's $\hat E = i\hbar\partial_t$ is not used); probability current $J$; inner product $\langle f\vert g\rangle = \int f^*g$, antilinear in the **first** slot (LADR and 556 are linear in the first slot); $\varphi(k)$ with $\Psi(x,0) = \frac{1}{\sqrt{2\pi}}\int\varphi(k)e^{ikx}dk$, $\Phi(p,t) = \varphi(p/\hbar,t)/\sqrt\hbar$ (WO's $\tilde f$: $\varphi = \sqrt{2\pi}\,\tilde f$); Gaussians $e^{-(x-x_0)^2/4\sigma^2}$ |
| Level B (QM): oscillator, 3D, spin | ladder operators $\hat a_\pm$ (PHY 308 and Zwiebach write $a^\dagger = \hat a_+$, $a = \hat a_-$), $\xi = \sqrt{m\omega/\hbar}\,x$; spherical $(r,\theta,\phi)$ with $\theta$ polar; $Y_\ell^m$ in Griffiths' 3rd-edition (Condon–Shortley) phases; $u = rR$; Bohr radius $a$ (level A writes $a_0$); in B5 $m_e$ is the electron mass and $m$ the magnetic quantum number, in B8 (Griffiths ch. 7) $m$ is the mass and $m_\ell, m_s, m_j$ the quantum numbers; spinors $\chi$, $\vec S = \frac\hbar2\vec\sigma$, gyromagnetic ratio $\gamma$ (B8.4 reuses $\gamma$ for Griffiths' Zeeman unit); Clebsch–Gordan phases of Griffiths' Table 4.8 |
| Level B (QM): approximations | $H = H^0 + \lambda H'$, $E_n^1$, $\psi_n^1$; electric field $\mathcal E$; WKB $p(x) = \sqrt{2m[E - V]}$, $\vert p\vert$ in forbidden regions, $\gamma = \frac1\hbar\int\vert p\vert dx$, $T \approx e^{-2\gamma}$ (the user's WKB notes write $\kappa$); exchange and direct integrals $K$, $C$ |
| Level B (EM): fields and sources | Griffiths' conventions in SI; separation vector $\vec{\mathcal R} = \vec r - \vec r\,'$, $\mathcal R = \lvert\vec{\mathcal R}\rvert$ (Griffiths' script r), primes on source coordinates, volume element $d\tau$; cylindrical $(s, \varphi, z)$ (level A and CM write $r$ for the cylindrical radius), azimuth always $\varphi$; densities $\lambda, \sigma, \rho$, currents $I, \vec K, \vec J$; potential $V$, configuration energy $W$, energy density $u$ (level A writes $U$ and $u_E$, $u_B$); torque $\vec N$ (level A: $\vec\tau$); magnetic moment $\vec m$ (level A and QM: $\vec\mu$); boundary normals point from medium 2 (below) to medium 1 (above) |
| Level B (EM): matter, induction, waves | $\vec P$, $\vec D = \varepsilon_0\vec E + \vec P$, $\chi_e$, $\varepsilon = \varepsilon_0\varepsilon_r$ (level A writes $\kappa$ for $\varepsilon_r$); $\vec M$, $\vec H$, $\chi_m$, $\mu$; conductivity $\sigma$, resistivity $\rho$ (clash with the charge densities flagged); magnetic flux $\Phi$ (level A: $\Phi_m$), emf $\mathcal E$; complex waves $e^{i(kz - \omega t)}$ as WO B8–B13; wave impedance $Z = \sqrt{\mu/\varepsilon}$; Griffiths' $\tilde k = k + i\kappa$ in conductors: $\kappa_G = \alpha_{\text{WO}} = \kappa_{\text{WO}}\,\omega/c$; stress tensor $\overleftrightarrow{T}$ with Griffiths' sign (Nelson uses $-T$); Levi-Civita $\epsilon_{ijk}$ |
| Level B (EM): potentials and radiation | gauge function $\lambda$ (CM writes $\chi$); Coulomb gauge $\nabla\cdot\vec A = 0$, Lorenz gauge $\nabla\cdot\vec A = -\mu_0\varepsilon_0\,\partial V/\partial t$, $\Box^2 = \nabla^2 - c^{-2}\partial_t^2$; retarded time $t_r$; Liénard–Wiechert $\vec u = c\hat{\mathcal R} - \vec v$, $\vec{\mathcal R}$ from the retarded position, $\vec R$ from the present one |
| Level B (REL): spacetime and tensors | Minkowski metric $\eta_{\mu\nu} = \mathrm{diag}(+1, -1, -1, -1)$ (the user's notes; the particle-physics/QFT convention — Griffiths ch. 12, Schutz and most GR texts use $-{+}{+}{+}$, converted where cited); $g$ reserved for curved metrics; $x^\mu = (ct, \vec x)$ with $c$ explicit (natural units start with QFT); Greek indices 0–3, Latin 1–3, Einstein summation; $\Lambda^\mu{}_\nu$ row $\mu$, column $\nu$; $B(\beta)$ the passive boost to a frame moving at $+\beta c$; rapidity $\varphi$ ($\beta = \tanh\varphi$); timelike $a^2 > 0$, future-pointing $a^0 > 0$; $\varepsilon^{0123} = +1$, $\varepsilon_{0123} = -1$; $\Box = c^{-2}\partial_t^2 - \nabla^2$ |
| Level B (REL): particles and fields | particle velocity $\vec u$, frame velocity $\vec v$ (as level A); $u^\mu = \gamma_u(c, \vec u)$, $p^\mu = (E/c, \vec p)$, $k^\mu = (\omega/c, \vec k)$ with plane waves $e^{-ik\cdot x}$; proper acceleration $\alpha$ ($a\cdot a = -\alpha^2$); Minkowski force $K^\mu$ (three-force $\vec F$); mechanical $\vec p$ vs canonical $\vec P$; Klein–Gordon field $\phi$ (rapidity $\varphi$); $A^\mu = (V/c, \vec A)$, gauge $A_\mu \to A_\mu + \partial_\mu\chi$ ($\chi = -\lambda$ of EM B); $F_{\mu\nu} = \partial_\mu A_\nu - \partial_\nu A_\mu$, $F^{0i} = -E_i/c$, $F^{ij} = -\varepsilon_{ijk}B_k$ (Griffiths' $F^{\mu\nu}$ is the negative), $J^\mu = (c\rho, \vec J)$ |
